## 1. 问题

列表拖排序时被抓的行半透明留在原位，其它行不让路，看不出会插到哪。日历日期行在滚动容器外，一出滚动条列缝就和表头错开；七天视图任务块左右各 6px 再加泳道间隙，几乎写不下字。详情顶栏灰底和设置页的浅底 + 卡片不一致。页头三个点占着「今日 / 统计」那种标题 | 说明的位置，添加分组却要先开一层「更多」。

## 2. 成功标准

| 项 | 必须 |
| --- | --- |
| 列表拖动 | 超过约 4px：原行从文档流消失，下方跟上；目标处（`beforeId` 前，或该组末尾）出现与行等高的空缝；指针上是圆角卡片浮动副本。跨分组同样插缝。拖到日历则取消列表空隙，改走现有半透明时间块 |
| 日历对齐 | 日期行与 24 小时格子在同一滚动容器内；日期行 sticky。列缝仍 10px、正中 1px `--hour-line`。有无滚动条，表头缝与格子缝水平对齐 |
| 任务块 | 3 天 / 7 天同一套：相对小时淡底左边 2px、右边 6px。今日计划列不改 |
| 详情 / 改期 | 面板 `bg-background`；名称、备注、时间控件在 `rounded-xl border bg-card` 卡片里。放弃、添加分组对话框不改 |
| 页头 | `任务 \| 未完成 n · 今日已排期 …`；右侧先硬币与能量，再 3 天 / 7 天。无三个点 |
| 空白右键 | 仅左侧列表滚动区空白：添加分组、显示/隐藏已完成。任务行、分组标题、勾选、输入框不走这套 |

明确不算失败：拖动中刷新板导致空隙闪一下；关窗时浮动卡片消失；Deferred 下页头能量与今日页同为预览数字。

## 3. 不变量

1. 拖排序、改期、开详情、加分组、显隐已完成都不发币。观测仍优先于计划。
2. 不引入 FullCalendar、dnd-kit、Radix、FLIP/动画 npm 库。颜色只来自 `--cat-*` / `theme.ts`。
3. 页面只经 `src/lib/api.ts` 调 `invoke()`。对话框仍不嵌套。
4. `user_version` **5**。备注仍不进 `TaskSnapshot`。
5. 多选不能整段拖排序；拖的只是抓住的那一条。Shift/⌘、勾选、单击详情规则不变。
6. 改 `src/` 跑 `npx vitest run --dir src`。本波不改 Rust 则不必重跑 `gamelife`；若误动 `src-tauri/` 则必须跑过。

## 4. 列表拖动

现有 `listDrag: { id, overListId, beforeId }` 保留，增加拖动开始时量到的 `rowHeight`。

超过 `CLICK_SLOP_PX`（4）之后：

1. 源列表不再渲染该行（或高度收到 0），下面的行用约 **160ms** 的 CSS 过渡跟上。原位不留洞。
2. 目标分组在 `beforeId` 那一行前面插入一块高度为 `rowHeight` 的空隙；`beforeId == null` 插在该组可见任务末尾。空隙是空的，不用强调色填满。
3. `position: fixed` 浮动副本（`bg-card`、圆角、浅阴影、`pointer-events-none`）跟随指针。
4. 跨分组：源组收拢，目标组出缝。不再把整组 `bg-accent/40` 当唯一提示（分组高亮可弱化或去掉）。
5. 指针进入日历格子：`listDrag` 清空（空隙与浮动卡片立刻拆掉），走现有 `beginCalDragAt(..., fromBlock: false)`。
6. 落到折叠分组（只能点到组头）= 接到该组末尾（`beforeId == null`）。

`pointerup` 仍用 `ranksAfterDrag` + `reorderTask` / `moveTask`。未超过 slop 的单击 / Shift / ⌘ 规则不变。

## 5. 日历

日期行从滚动容器外挪进与格子**同一个** `overflow-auto`。日期行 `sticky top-0`、不透明卡片底，避免小时线透上来。`CAL_GUTTER` / `CAL_DAY_GAP` / `hitCalendarTs` 几何不变。第一列与小时槽之间仍不加日缝。

任务块（3 天与 7 天相同）：

```
left:  calc(lane% + 2px)
width: calc(span% - 2px - 6px - 4px)   /* 左 2 + 右 6 + 原泳道 4 */
```

小时淡底仍铺满列宽，从块两侧露出。今日计划列不画淡底、不改这套 inset。

## 6. 详情与改期底色

`TaskDetailDialog` 与 `TaskDateDialog`：

- 面板浅底 `bg-background`。去掉默认顶栏 / 底栏的 `bg-muted/30`（可给 `Dialog` 加可选无灰条样式，或这两处自绘页眉页脚）。
- 名称、备注、时间字段分组放进 `rounded-xl border bg-card` 卡片。
- 勾选、失焦保存、400ms 备注、Markdown 子集、底栏分组 Select 与「…」、改期「确定 / 清除」行为不变。

放弃确认、添加分组、列表「更多」不再存在后的其它确认框：保持现有简单 `Dialog`。

## 7. 页头

`PageHeader`：

- 标题：任务
- 字幕：`未完成 n · 今日已排期 d`  
  - `n` = 整板 `!done` 条数（含折叠组里的未完成）。  
  - 已排期 = 未完成任务与**今天** `[dayStart, dayStart+86400)` 相交的秒数之和。  
  - `d`：相交 0 → `0 分钟`；1–3599 秒 → `m 分钟`（`ceil(secs/60)`，1 秒也是 `1 分钟`）；≥ 3600 秒 → 一位小数小时，去掉末尾 `.0`（`2 小时` / `1.5 小时`）。
- `actions` 左侧：与商店相同的 `◉ {coinBalance}`、`⚡ {xpToday}`，数据来自 `getToday()`（与侧栏同一命令）。右侧仍是 3 天 / 7 天 `Segmented`。

空板：`未完成 0 · 今日已排期 0 分钟`；硬币能量仍显示。

## 8. 列表空白右键

删除页头三个点及「更多」对话框。

左侧列表 `overflow` 滚动容器上 `contextmenu`：若命中任务行、分组标题按钮、勾选框、自然语言输入，不拦（走现有菜单或不管）。否则 `preventDefault`，弹出：

- 添加分组（打开现有添加分组对话框）
- 显示已完成 / 隐藏已完成（现有 `showDone` 开关）

日历空白、分割条、页头不弹这套。

## 9. 分层

```
PageHeader
  任务 | 未完成 n · 今日已排期 d     ◉ ⚡     3天/7天

列表
  浮动卡片 + 空隙占位 · 空白右键加组/显隐完成 · 多选不变

日历
  sticky 日期行与格子同宽 · 块 2px/6px

TaskDetailDialog / TaskDateDialog
  浅底 + bg-card 分组
```

纯函数（可测）：已排期相交秒数与时长文案；拖动时可见序列（去掉 `dragId` 后在 `beforeId` 前插入空隙下标）。现有 `ranksAfterDrag` / `hitCalendarTs` / `hourWashCategory` 不改语义。

## 10. 不做

- 日历或今日计划列的列表式空隙动画。
- 多选整段拖排序。
- 新动画库、dnd-kit、Radix。
- 为任务页新做结算；页头只读 `getToday()`。
- 改 `user_version`、备注进判定。
- 放弃 / 添加分组对话框改成卡片叠层。

## 11. 测试

前端：

- 今日已排期：无相交 → 0；跨午夜只计今天这一段；文案 59 分钟 / 1 小时 / 1.5 小时。
- 拖动可见序列：源 id 不在原位；空隙在 `beforeId` 前；跨组 `beforeId == null` 在目标组末尾。
- `npx vitest run --dir src`。
