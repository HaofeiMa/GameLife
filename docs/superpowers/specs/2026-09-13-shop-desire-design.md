# GameLife H：商店欲望（视觉与节奏，不改经济）

日期：2026-09-13  
状态：待用户审阅  
范围：让商店页值得打开：钱包英雄区、更大的礼品卡、解锁过程可见、进行中的娱乐是一张活卡片、兑换记录像回执而不是后台表。 **不改** 价格公式、解锁门槛（当天主线 credited ≥ 3600 秒）、单事务兑换、同时一段娱乐、Gold Day 停发、无系统通知。

覆盖 `2026-09-11-planner-shell-design.md` §9 与 `2026-09-11-game-feel-design.md` 的 **呈现**，不覆盖那些文档里的事务与错误码。

依赖活动监测 spec 的导航与中文徽章语言。统计页不承担兑换。

## 1. 问题

现在的礼品卡偏小、顶栏信息弱、锁定时只剩一行警告。监测器靠硬币和能量闭环；商店如果看起来像设置里的表单，使用者没有「再多做一格主线」的理由。

## 2. 成功标准

| 项 | 必须 |
| --- | --- |
| 钱包 | 进入商店先看到硬币余额、今日能量、解锁状态。未解锁时是进度条（距 60 分钟主线还差多少），不是只有一句红字 |
| 进行中 | 未结束的能量兑换是一张置顶大卡：名称、剩余 mm:ss、到期时刻。到点且窗口开着：现有 toast。倒计时仍不豁免娱乐判定 |
| 货架 | 硬币 / 能量两栏。卡片约 160–180px 宽，不再 112px 小方块。渐变 + 首字或内联 SVG（茶、餐、书、播放、手柄），禁止 Habitica 素材 |
| 锁定 | 未解锁时卡片仍展示但兑换按钮禁用，按钮文案「差 N 分钟」。黄金日后仍可花已有余额 |
| 空店 | 保留一次示例种子（奶茶 32、外卖 64、新书 48、B 站 45、游戏 30、短视频 15）。种子之后可改名改价停用 |
| 记录 | 时间、商品、类型、扣额、状态；进行中高亮。只读不可撤单 |
| 手感 | 兑换成功：卡片短暂确认态 + 钱包数字变化；失败：现有错误码中文（余额不足、娱乐进行中、商店锁定等） |

明确不算失败：关窗错过 toast；无新音效；无真实下单。

## 3. 不变量

1. `validate_redeem` / `validate_wish` / `UNIQUE redemption_id` / 单事务 rollback 不变。
2. 能量愿望必须 `duration_minutes ≥ 5`；硬币愿望不得带时长。
3. 同时最多一段 `now < ends_at` 的娱乐会话。
4. 无系统通知、无音效。
5. 界面只说「能量」不说 XP。
6. 改商店相关 Rust 后仍跑 `cargo test --offline -p gamelife`；前端 `npx vitest run --dir src`。
7. 测试禁止 `std::env::set_var("HOME", …)`。

## 4. 页面结构

从上到下：

1. **英雄区**（全宽圆角白底，与今日页面板同一圆角语言）  
   - 左：硬币大数字 + 「可兑换愿望」  
   - 中：今日能量 + 若有进行中会话则改显示剩余时间  
   - 右：解锁。未解锁：环形或条，分子为今日 credited 分钟 cap 在 60。已解锁：勾与「商店已开」。黄金日：旁注「不再获得新币，余额可继续花」。
2. **进行中娱乐卡**（无会话则整卡不渲染，避免空壳）  
   大号剩余时间、商品名、「结束后仍按规则判定娱乐」。
3. **硬币货架** / **能量货架**  
   CSS grid：`repeat(auto-fill, minmax(160px, 1fr))`，间距足够点按。每张卡：glyph、名称（两行截断）、价格（硬币或能量）、主按钮「兑换」、次级「改 / 停用」。能量卡额外一行「N 分钟」。
4. **添加**  
   每栏末张虚线「+」展开为卡内表单（名称、价格、能量时长），与现网相同校验。
5. **兑换记录**  
   最近 30 条。进行中一行用能量色左边框。状态文案：进行中 / 已结束 / 硬币已兑。

顶栏不再用两枚缩略徽章重复英雄区数字。权限条不在商店页（在今日）。娱乐 Banner 若与置顶大卡重复，商店页 **只保留大卡**，去掉第二条横幅。

## 5. 视觉

- 硬币卡：暖金渐变（现网 `#fef3c7 → #fde68a` 加深可用对比）。
- 能量卡：蓝渐变（现网能量色）。进行中卡可用更深蓝并加脉冲只动剩余数字，不整页闪。
- 禁用：对比度仍可读，不要 `opacity: 0.2` 到看不清价格。
- 深色导航栏已存在；商店内容区保持浅底，与今日/统计一致。
- 图标用简单几何 SVG 或名称首字，不引入图标字体包也可以。

## 6. 交互

- 兑换中按钮禁用；全局仍用现有 in-flight 锁防止双击。
- 停用：卡变灰，不出现在「可兑」视觉优先序，仍可在编辑里恢复（现网 archive 语义）。
- 改价：未兑愿望可改；已有兑换记录的历史行显示当时名称（`redemptions.name`），不随愿望改名回溯。
- 不在商店做任务列表、不在商店显示 15 分钟轴。

## 7. 错误文案（中文，已有码则沿用）

| 码 | 文案 |
| --- | --- |
| `shop_locked` | 估计有效主线未满 60 分钟，商店未开 |
| `insufficient` | 余额不足 |
| `entertainment_in_progress` | 已有一段娱乐在计时 |
| `entertainment_needs_duration` | 能量兑换至少 5 分钟 |
| `wish_missing` / `wish_archived` | 这张卡不可兑 |
| `already_applied` | 静默当成功（幂等），UI 刷新即可 |

## 8. 测试要点

- 未解锁：按钮 disabled，文案含剩余分钟；英雄区进度分母 60。
- 解锁后能量卡可点；进行中再兑能量失败且不扣第二次。
- 空愿望表启动仍只种子一次。
- 兑换记录只读；改愿望名不改历史行。
- 无新增系统通知 API。

## 9. 明确不做

- 把愿望镜像成 TickTick 清单 + 标签来完成即兑换。
- 真实支付、快递、库存动画包。
- 等级、掉落、Habitica 音效与立绘。
- 为「好看」放宽解锁门槛或 Gold Day。
