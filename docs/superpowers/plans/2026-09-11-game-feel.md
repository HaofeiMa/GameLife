```rust
pub fn validate_wish(name: &str, kind: &WishKind, price: i64) -> Result<(), WishError> {
    let name = name.trim();
    if name.is_empty() {
        return Err(WishError::EmptyName);
    }
    if name.chars().count() > 80 {
        return Err(WishError::NameTooLong);
    }
    if price <= 0 {
        return Err(WishError::NonPositivePrice);
    }
    match kind {
        WishKind::Xp { duration_minutes } => match duration_minutes {
            Some(d) if *d >= 5 => Ok(()),
            _ => Err(WishError::EntertainmentNeedsDuration),
        },
        WishKind::Coin => Ok(()),
    }
}

pub fn has_entertainment_timer(kind: &WishKind) -> bool {
    matches!(kind, WishKind::Xp { duration_minutes: Some(d) } if *d >= 5)
}

pub fn can_start_entertainment(now: i64, active_ends_at: Option<i64>) -> bool {
    match active_ends_at {
        Some(ends) if now < ends => false,
        _ => true,
    }
}

pub fn entertainment_remaining_secs(now: i64, ends_at: i64) -> i64 {
    ends_at - now
}

pub fn tray_entertainment_minutes(remaining_secs: i64) -> Option<u32> {
    if remaining_secs <= 0 {
        None
    } else {
        Some(u32::try_from((remaining_secs / 60).max(1)).unwrap_or(1))
    }
}
```

### Task 4: redeem 写入会话并返回 Rejected

**Files:**
- Modify: `src-tauri/src/db_error.rs`
- Modify: `src-tauri/src/db.rs`（`redeem` 签名与实现）
- Modify: 所有 `redeem(` 调用点（`commands.rs` 与 `db.rs` 测试）

**Interfaces:**
- Consumes: `can_start_entertainment`、`has_entertainment_timer`、`validate_redeem`
- Produces:

```rust
pub enum DbOpError {
    AlreadyApplied,
    Busy,
    Rejected(String),
    Fatal(String),
}

pub fn redeem(
    conn: &mut Connection,
    credited_today: i64,
    day: &str,
    wish: &Wish,
    wish_name: &str,
    now: i64,
    redemption_id: &str,
) -> Result<(), DbOpError>
```

事务内：

1. 读 coin 全历史、当日 xp（与现网一致）
2. 若调用方已确认愿望存在；本函数不查 archived（命令层查）。`validate_redeem` 失败 → `Rejected` 码：`shop_locked` / `insufficient` / `entertainment_needs_duration`
3. 查 `SELECT MAX(ends_at) FROM entertainment_sessions`（或最新 ends_at）。`has_entertainment_timer` 且 `!can_start_entertainment(now, active)` → `Rejected("entertainment_in_progress")`，不写
4. `INSERT redemptions (redemption_id, wish_id, ts, name, duration_minutes)`。UNIQUE → AlreadyApplied（在写 session 前失败则无 session）
5. `INSERT shop_spend`
6. 若 `has_entertainment_timer`：`ends_at = now + duration_minutes * 60`，`duration` 取 `Xp { Some(d) }`，插入 `entertainment_sessions`

`map_redeem_error(e: RedeemError) -> DbOpError`：

```rust
match e {
    RedeemError::ShopLocked => DbOpError::Rejected("shop_locked".into()),
    RedeemError::Insufficient => DbOpError::Rejected("insufficient".into()),
    RedeemError::EntertainmentNeedsDuration => {
        DbOpError::Rejected("entertainment_needs_duration".into())
    }
    RedeemError::EntertainmentInProgress => {
        DbOpError::Rejected("entertainment_in_progress".into())
    }
    RedeemError::WishArchived => DbOpError::Rejected("wish_archived".into()),
    RedeemError::WishMissing => DbOpError::Rejected("wish_missing".into()),
    RedeemError::FinalSlotImmutable => DbOpError::Fatal("final".into()),
}
```

```ts
export type FeelNotice =
  | { type: "coins"; n: number }
  | { type: "xp"; n: number }
  | { type: "chest" }
  | { type: "goldDay" }
  | { type: "earlyStart"; coins: number }
  | { type: "streak"; n: number }
  | { type: "redeem" }
  | { type: "entertainmentOver"; name: string };

export type LedgerRow = { key: string; coin: number; xp: number; ts: number };

export function coalesceFeelEvents(rows: LedgerRow[]): FeelNotice[]

export function nextFeelNotices(
  prevMaxTs: number | null,
  rows: LedgerRow[],
): { notices: FeelNotice[]; maxTs: number | null }

export function sessionJustEnded(
  prevRemaining: number | null,
  active: { remainingSecs: number } | null,
): boolean
```

`nextFeelNotices`：`prevMaxTs === null` → notices `[]`，`maxTs = max(rows.ts)` 或 `null`（无行）。否则过滤 `ts > prevMaxTs` 再 coalesce，新水位为全部 rows 的 max ts 与 prev 的较大值。

`sessionJustEnded`：`prevRemaining !== null && prevRemaining > 0 && active === null`。

`App.tsx`：`useEffect` 每 5s `getToday()`，维护 `prevMaxTs`、`prevRemaining`、`toasts: {id, text}[]`。把 notices 映射中文：

- coins → `+{n} Coins`
- xp → `+{n} XP`
- chest → `Chest`
- goldDay → 现有 Gold Day 英文句可缩短为 `Gold Day`
- earlyStart → `Early start +{coins}`
- streak → `连胜 {n}`
- redeem → `已兑换`
- entertainmentOver → `{name} 时间到`

Toast CSS：右上角固定，3 秒后移除。不要系统通知。
